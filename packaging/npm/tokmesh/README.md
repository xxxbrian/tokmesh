# tokmesh

Single npm package for the [tokmesh](https://github.com/xxxbrian/tokmesh) CLI.

```sh
npm install -g tokmesh
tokmesh --help
# or
npx tokmesh --help
```

On install (and on first run if needed), the package downloads the matching
prebuilt binary from [GitHub Releases](https://github.com/xxxbrian/tokmesh/releases)
for your OS/CPU. There are no extra platform packages to install.
